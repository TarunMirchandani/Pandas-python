# Pandas-python
Pandas is an open-source Python library used for data manipulation, analysis and cleaning.

This repository is dedicated to exploring the capabilities of the Pandas library, featuring data manipulation workflows, cleaning techniques, and comprehensive analysis scripts.

## Features

With this library we can import, export, display, and manipulate data.


- Data cleaning and preprocessing pipelines
- Handling missing data and outliers
- Grouping, merging, and joining datasets
- Time-series data analysis
- Exploratory Data Analysis (EDA) examples

## Installation

To run the scripts in this repository, you need to install Pandas. You can install it via pip:

```bash
pip install pandas
```
